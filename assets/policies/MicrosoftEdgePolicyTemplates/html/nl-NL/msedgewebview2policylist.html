Microsoft Edge WebView2 - Beleid

De nieuwste versie van Microsoft Edge WebView2 bevat de volgende beleidsregels. Met deze beleidsregels kunt u configureren hoe Microsoft Edge WebView2 wordt uitgevoerd in uw organisatie. Voor informatie over een aanvullende reeks van beleidsregels die u kunt gebruiken om te bepalen hoe en wanneer Microsoft Edge WebView2 wordt bijgewerkt, raadpleegt u Verwijzing naar updatebeleid voor Microsoft Edge

OPMERKING

Dit artikel is van toepassing op Microsoft Edge versie 87 of hoger.

Deze tabellen bevatten alle groepsbeleidsregels die beschikbaar zijn in deze release van Microsoft Edge WebView2. Gebruik de koppelingen in de tabel voor meer informatie over specifiek beleid.

BrowserExecutableFolder

De locatie van de uitvoerbare map van de browser configureren

Ondersteunde versies:
  • Op Windows vanaf 87 of later
Beschrijving
Dit beleid configureert WebView2-toepassingen om de WebView2 Runtime in het opgegeven pad te gebruiken. De map moet de volgende bestanden bevatten: msedgewebview2.exe, msedge.dll, enzovoort.

Geef een waarde-naam en waarde-paar op om de waarde voor het mappad in te stellen. Stel de waardenaam in op de Gebruikersmodel-ID van de toepassen of de naam van het uitvoerbare bestand. U kunt het jokerteken '*' als waardenaam gebruiken voor alle toepassingen.
Ondersteunde functies:
  • Kan verplicht zijn: Ja
  • Kan worden aangeraden: Nee
  • Dynamische beleidsvernieuwing: Ja
Gegevenstype:
  • Lijst met tekenreeksen
Windows-informatie en -instellingen
Info over groepsbeleid (ADMX)
  • Unieke GP-naam: BrowserExecutableFolder
  • GP-naam: De locatie van de uitvoerbare map van de browser configureren
  • GP-pad (Verplicht): Beheersjablonen/Microsoft Edge WebView2/Overschrijvingsinstellingen voor laadprogramma
  • GP-pad (Aanbevolen): N.v.t.
  • GP ADMX-bestandsnaam: MSEdgeWebView2.admx
Windows-registerinstellingen
  • Pad (Verplicht): SOFTWARE\Policies\Microsoft\Edge\WebView2\BrowserExecutableFolder
  • Pad (Aanbevolen): N.v.t.
  • Waardenaam: lijst met REG_SZ
  • Waardetype: lijst met REG_SZ
Voorbeeldwaarde:
SOFTWARE\Policies\Microsoft\Edge\WebView2\BrowserExecutableFolder = "Name: *, Value: C:\\Program Files\\Microsoft Edge WebView2 Runtime Redistributable 85.0.541.0 x64"

ReleaseChannelPreference

De voorkeur voor de zoekvolgorde van vrijgavekanalen instellen

Ondersteunde versies:
  • Op Windows vanaf 87 of later
Beschrijving
De standaard zoekvolgorde voor kanalen is WebView2 Runtime, Bèta, Dev en Canary.

Stel dit beleid in op 1 om de standaardzoekvolgorde om te keren.

Geef een waarde-naam en waarde-paar op om de waarde voor de voorkeur voor het releasekanaal in te stellen. Stel de waardenaam in op de Gebruikersmodel- ID of de naam van het uitvoerbare bestand. U kunt het jokerteken '*' als waardenaam gebruiken voor alle toepassingen.
Ondersteunde functies:
  • Kan verplicht zijn: Ja
  • Kan worden aangeraden: Nee
  • Dynamische beleidsvernieuwing: Ja
Gegevenstype:
  • Lijst met tekenreeksen

  • GP-pad (Aanbevolen): N.v.t.
